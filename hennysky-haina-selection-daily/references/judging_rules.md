# 看图判断规则

## 核心原则

MCP 返回的 `analysis` 是未开视觉的模型凭标题猜的，**只当作待验证的假设**。真实结论必须来自逐张看图。看图后逐条写「纠正：原来猜 X，实际是 Y」，这是报告最有价值的部分。

## 每张图必看的 6 件事

1. **主体**：到底画的是什么（人 / 动物 / 风景 / 静物 / 纯抽象）。
2. **构图**：居中 / 留白 / 横向分层 / 俯拍 / 特写。
3. **主色调**：冷暖、明暗、是否发灰。
4. **风格**：写实 / 复古插画 / 表现主义 / 极简肌理 / 波普拼贴 / 金色装饰。
5. **场景**：客厅沙发墙 / 卧室床头 / 玄关 / 儿童房 / 咖啡角。
6. **风险**：印刷是否显廉价、运输是否易损、受众是否太窄、题材是否同质化。

## 五级分类标准

| 级别 | 判定标准 |
|---|---|
| **值得跟进** | 画面本身有记忆点 + 有真实市场验证（评论数高）或风格成体系可成套引进 + 风险可控可打样验证。 |
| **谨慎** | 画面好看但存在明确量产风险：金箔/金粉印刷易显廉价、石膏肌理运输易碎、大尺幅对墙面要求高、只有缩略图看不清细节。先打样再定。 |
| **小众** | 画面看懂了，但题材受众窄（迷你原画、限量艺术版、人物情绪画）或与量产逻辑不符，只作方向参考。 |
| **常规** | 画面确认了但同质化高、辨识度低，或评论极少市场验证弱，暂不列重点。 |
| **无图** | 平台禁抓 / 超时 / 页面拒绝，只能靠标题价格判断，不当结论用。 |

## 常见标题推断错误（真实案例，务必警惕）

这些是 2026-11-25 实测中模型凭标题猜错、看图后纠正的典型：

| 编号 | 只凭标题的推断 | 看图后的真实画面 |
|---|---|---|
| S602「Have You Seen Bert?」 | 棕色长毛小狗，宠物画 | 黑猫蹲在自助洗衣店三张黄色椅子上，复古叙事插画 |
| S603「Waiting Game」 | 画面看不清，无法判断 | 女子躺橄榄绿沙发够地上的书+猫，60 年代复古插画 |
| S601「石榴鸡尾酒」 | 扁平叙事插画，细节看不清 | 俯拍野餐场景，绿草地+红粉食物，装饰写实、细节丰富 |
| ETS03「肌理石膏三件套」 | 3 件套 | 展示图里只有 2 联，件数待确认 |
| SAA02「Pink flower with cat」 | 猫和粉花静物 | 红发女子抱黑猫，表现主义人像 |
| ETS02「克里姆特蜂鸟」 | 简单金色抽象 | 金箔马赛克底+彩绘蜂鸟，华丽但印刷易翻车 |

**规律**：标题里的动物、花、颜色词常常会让模型脑补出"静物/宠物画"，实际可能是场景叙事或人像。凡标题含动物名，必须看图确认主体到底是谁。

## 装饰画选品的固定风险清单

套用到每一款，命中就在结论里点出来：

- **印刷风险**：金色/金箔/金粉易显廉价发土；雾景、白色花卉在浅色墙易发灰发闷；风景画色彩还原偏灰。
- **运输风险**：石膏肌理画、厚涂立体画易磕碰破损；大尺幅（54x72、60x30）运输和挂装成本高。
- **尺寸风险**：8x10 偏小，挂大墙显单薄；60x30 横幅对墙面宽度要求高；原画（手掌大小）走周边而非量产。
- **版权风险**：蒙德里安几何、克里姆特风格、国家公园题材、名画二创需确认原创性和授权边界。
- **受众风险**：人物情绪画、强烈波普、成人趣味拟人动物受众窄；宠物+花卉题材同质化严重。
- **同质化风险**：写实风景（雾山、国家公园）、花卉静物市面存量巨大，需看实物画功和辨识度。

## 判断的正向信号

- 评论数高（如 WF03 的 369 条）→ 有真实走量，优先看。
- 同一画师多款风格成体系 → 适合成套引进，比单张更有价值。
- 高价大尺幅带框画（CB2 $299~499）→ 价格带值得对标，即使画面不跟也要记录。
- 画面有"记忆点"（反差配色、叙事场景、独特肌理）→ 比稳妥但平庸的款更值得跟。
