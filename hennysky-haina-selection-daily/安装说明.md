# 选品日报 skill · 安装说明

给谁看：想每天一句话就拿到「亚马逊装饰画新品日报 + 看图报告」的同事。全程约 5 分钟（主要看有没有现成的数据源）。

---

## 这个 skill 是干什么的

说一句「跑今天的选品日报」，它会自动跑完整条链路：

1. **拉数据** —— 从 haina-selection 数据源拿当天新品（平台、标题、价格、尺寸、评论、图片地址）
2. **出日报** —— 对话里先给清单表格 + 趋势信号 + 数据坑提醒
3. **抓图** —— 批量下载能抓的商品图
4. **逐张看图** —— 实际打开每张图，纠正源数据里凭标题瞎猜的错误
5. **出报告** —— 生成一页式 HTML 看图报告，按「值得跟进 / 谨慎 / 小众 / 常规 / 无图」分级，自动打开

为什么要有第 4 步：数据源里的 AI 分析没开视觉，只凭标题猜，实测把「洗衣店里的黑猫」猜成「棕色小狗」，错误率很高。所以必须看图再下结论，这是这个 skill 最值钱的地方。

---

## 前置依赖：一个叫 haina-selection 的数据源

这个 skill 本身是纯文件（Python 脚本 + Markdown + HTML 模板），**但它依赖一个 MCP 数据源来取新品数据**。没有它，skill 跑不起来。

数据源是内部服务，地址和访问密钥需要**向管理员要两样东西**：

1. **服务地址**（形如 `http://.../mcp`）
2. **Bearer token**（一串密钥）

> 这两样是账号凭证。本仓库**不包含也不允许提交**任何真实地址密钥或 token，文档里全是占位符。请从管理员处获取，别在群里公开转发。

## 安装步骤

### 第 1 步：拿到文件夹

把整个 `hennysky-haina-selection-daily` 文件夹放到：

```
~/.workbuddy/skills/hennysky-haina-selection-daily
```

> `~` 是用户主目录。访达里按 `Cmd+Shift+G` 输入 `~/.workbuddy/skills` 回车打开；`skills` 不存在就新建一个。文件夹名不要改。

### 第 2 步：自检

在终端里执行：

```bash
python3 ~/.workbuddy/skills/hennysky-haina-selection-daily/scripts/doctor.py
```

脚本会告诉你三件事：mcp.json 里有没有配这个数据源、配置全不全、能不能连上。它**只读本地配置探活，不打印 token，不上传任何东西**。

- 全部 `[OK]` → 数据源已就绪，跳到第 4 步。
- 报「没找到 mcp.json / 里面没有 haina-selection」→ 做第 3 步配置。

### 第 3 步：配置数据源（需要管理员给的地址和 token）

在 WorkBuddy 里说这句话就行，不用自己改 JSON：

> 帮我配置一个叫 haina-selection 的 MCP，地址是「粘贴地址」，token 是「粘贴 token」，写到 ~/.workbuddy/mcp.json 的 mcpServers 里，保留已有的其它 MCP 不要覆盖。

或者自己编辑 `~/.workbuddy/mcp.json`，在 `mcpServers` 里加（**保留已有条目**）：

```json
"haina-selection": {
  "type": "streamableHttp",
  "url": "管理员给的地址",
  "headers": {
    "Authorization": "Bearer 管理员给的token"
  },
  "timeout": 60000
}
```

配完还有**两步容易漏**：

1. 在 WorkBuddy 左下角连接器管理页，找到新加的 `haina-selection`，点「信任 / 启用」。新 MCP 不会自动生效。
2. 重启 WorkBuddy。重启后 ToolSearch 才能搜到这个数据源的工具。

再跑一次 doctor.py，全部 `[OK]` 即成功。

### 第 4 步：验证能跑

重启 WorkBuddy 后，在对话里说：

> 跑一下今天的选品日报

能先出文字日报、再抓图、最后弹出一份看图报告，就对了。想只要文字不要图，就说「只要文字日报」。

## 常见问题

**没装 MCP 会怎样**

不会直接崩。skill 会先自检，发现没配就告诉你「需要服务地址和 token，找管理员要」，并引导配置，而不是甩一个报错。

**token 会不会被传出去 / 提交到仓库**

不会。token 只存在你本机的 `~/.workbuddy/mcp.json`，那是你的私有配置。skill 的所有文档和脚本里都是占位符，doctor.py 打印地址时还会截断、从不打印 token。

**数据源连不上 / token 过期**

跑 doctor.py 会明确告诉你是地址错、token 失效还是网络问题。找管理员换 token 后重配即可。

**某天数据库里没新品**

skill 以库里最新有数据的日期为准，不会硬报「今天」。报告里会写明实际日期。

**想每天自动跑**

配好后可以建一个每天固定时间的自动化任务，prompt 就写「跑一下今天的选品日报」。

**抓不到图**

有些平台禁止程序下载图（如 Minted），或页面超时（如 Saatchi）。这些款会在报告里单列「没抓到图的 N 款」，不会瞎编结论。
