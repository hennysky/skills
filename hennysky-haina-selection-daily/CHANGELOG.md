## 1.1.1 — 2026-11-25

- 新增 `使用指南-发同事.md`：面向电脑小白同事的转发模板——首次安装七步（含 MCP 未配时找管理员要地址+密钥的分支）、日常一句话使用、skill/MCP/提示词的大白话解释、出问题两句话处理办法。

## 1.1.0 — 2026-11-25

- 报告商品链接的按钮从标题后移到卡片底部，改成整行「在 XX 平台查看商品页 ↗」，消除长短标题导致的按钮错位。
- 修复无图款商品页链接未生成的问题：原匹配规则要求编号后紧跟结束标签，但实际是「编号 + 中文标题」连写，导致 4 款（Minted 3 款、Saatchi 1 款）按钮缺失。现按行首编号识别，4 款全部补上。
- 模板注释与 SKILL.md 同步记录两处坑：标题后不要塞按钮；判断行内是否已有按钮不能用「打开商品页」字样（原文可能本来就有这句话）。
- 新增 MCP 未安装时的完整处理链路：Step 0 前置检查、`scripts/doctor.py` 自检、首次配置引导、安全红线（token 不进仓库）。装了 skill 没装数据源时不再简单报错，而是引导用户找管理员要地址和 token 并协助配置。
- 新增 `安装说明.md`（面向不懂技术的同事）与 `references/mcp-setup.md`（给 Agent 的处理指引）。
- 未改动数据拉取与看图判断逻辑；1.0.x 的能力继续保持。

## 1.0.1 — 2026-11-25

- 报告每款商品新增可点击的商品详情页链接：取 `get_items` 的 `url` 字段，图片、标题、按钮三处可点；无图款清单也带链接。

## 1.0.0 — 2026-11-25

- 建立选品日报独立技能，端到端六步：MCP 拉数据 → 对话出文字日报 → 批量抓图 → 逐张看图纠正 → 生成分级看图报告 HTML → 打开预览。
- 五级分类标准（值得跟进 / 谨慎 / 小众 / 常规 / 无图）、看图 6 项检查清单、6 个真实标题推断错误案例、装饰画选品固定风险清单。
- `scripts/fetch_images.py` 批量抓图（跳过无图、输出 manifest），已实测普通 URL 与 CB2 特殊字符 URL。
- `assets/report_template.html` 一页式报告骨架，含全部 CSS 与完整卡片样例。
- 数据源为自定义 MCP `haina-selection`，不含任何账号凭证。
