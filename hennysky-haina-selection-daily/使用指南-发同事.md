# 发同事的使用说明（转发模板）

> 用途：把本文整体复制发给要使用「选品日报」的同事。发之前把两处 **【填联系人】** 改成实际的数据源管理员。
> 配套的安装提示词见文末——同事粘贴给他自己的 WorkBuddy 即可从 GitHub 自动安装。

---

【选品日报使用说明 · 看完就能用】

**这是什么**：每天早上各平台的新品装饰画，AI 自动抓图、看图、出一份能点开商品页的看图报告。你装一次，以后每天说一句话就行。

**一、首次安装（约 10 分钟，只需做一次）**

1. 把文末那段「安装提示词」复制粘贴发给你的 WorkBuddy，它会自动从 GitHub 下载并帮你装好
2. 按它提示重启一次 WorkBuddy
3. 然后你说一句：「跑一下今天的选品日报」
4. 如果它提示缺数据接口（MCP），你需要找 **【填联系人】** 要两样东西：**服务地址 + 密钥**，**私聊**发给 WorkBuddy，它会帮你配好（别发群里，密钥不外传）
5. 按提示去连接器页面点一下「信任」、再重启一次
6. 再说一次「跑今天的选品日报」——报告自动弹出来，就装好了

**二、装好之后，每天只用说这一句**

> 跑一下今天的选品日报

想看某天的就说「跑 11 月 20 日的」；只想要文字不要图，就说「只要文字日报」。

**三、两个词解释一下**

- **技能（skill）**：一本操作手册，教 AI 按固定流程干活，装一次一直用
- **MCP**：一根数据水管，一头连公司的选品数据库，一头连你的 WorkBuddy，所以要地址和密钥才能接上

**四、出问题怎么办**

- 报告没出来 → 跟 WorkBuddy 说「帮我跑一下 doctor 检查」
- 连不上数据 → 密钥可能过期了，找 **【填联系人】** 换一个

---

## 安装提示词（同事复制给他的 WorkBuddy）

```text
请帮我安装「选品日报」技能（hennysky-haina-selection-daily）。

1. 从 GitHub 下载仓库：git clone --depth 1 https://github.com/hennysky/skills.git 到一个临时目录，只把其中的 hennysky-haina-selection-daily 文件夹复制到 ~/.workbuddy/skills/，其余文件夹不要。
2. 运行 python3 ~/.workbuddy/skills/hennysky-haina-selection-daily/scripts/doctor.py 自检数据源。
3. 如果 doctor 提示缺 haina-selection 数据源：我会把服务地址和 token 私下发给你，帮我写进 ~/.workbuddy/mcp.json 的 mcpServers 里，保留已有条目不要覆盖。这是密钥，不要复述、不要写进任何别的文档。
4. 配置写完后，告诉我去哪里点「信任」、要不要重启 WorkBuddy，我照做之后你再重跑一次 doctor，直到全部 OK。
5. 都 OK 后，我说「跑今天的选品日报」来验证。

完成后告诉我「已装好」。
```
