# 汇报 skill · 安装说明

给谁看：想把「汇报 skill」装到自己电脑上的同事。全程 3 步，5 分钟。

---

## 这个 skill 是干什么的

把零散的工作内容做成一份能直接交出去的汇报：

1. **先问你是什么汇报** —— 双周汇报 / 月度总结 / 专项汇报 / 转正述职 / 年度复盘 / 申请报销
2. **按类型配一套去 AI 味规则** —— 不同汇报的 AI 味病灶不一样，规则也不一样
3. **先出大纲** —— 只出章节骨架给你确认，不会一次写满
4. **再填内容** —— 按你确认的结构填要点，每节 3～5 条
5. **最后出页面** —— 生成一份能直接打开、能打印成 PDF 的 HTML 汇报页

内置了一套汇报措辞规则（比如"问题"改写成"现状/方向/价值"），以及六套分别定制的去 AI 味规则。

---

## 安装三步

### 第 1 步：拿到文件夹

你会收到一个叫 `report-briefing` 的文件夹（压缩包就先解压）。

### 第 2 步：放到技能目录

把整个 `report-briefing` 文件夹放进去：

```
~/.workbuddy/skills/
```

完整路径就是 `~/.workbuddy/skills/report-briefing`。

> `~` 是你的用户主目录（访达里按 `Cmd+Shift+G` 输入 `~/.workbuddy/skills` 回车即可打开）。如果 `skills` 文件夹不存在，新建一个。

### 第 3 步：重启 WorkBuddy

完全退出 WorkBuddy 再打开（不是只关窗口）。新技能在重启后才会被识别。

---

## 验证装好了

重启后随便开一个对话，说：

> 用汇报 skill，帮我写本期双周汇报的大纲

如果 AI 开始**先问你确认骨架**（只出章节标题，不写满内容），说明装好了。

也可以直接检查文件在不在：

```bash
ls ~/.workbuddy/skills/report-briefing/SKILL.md
```

## 里面有什么

```
report-briefing/
├── SKILL.md                    AI 的入口说明（怎么判断场景、按什么流程走）
├── references/
│   ├── 去AI味规范.md            通用硬禁 10 组 + 六类汇报各自的专项规则
│   ├── 内容规范.md              措辞规则：现状/方向/价值、不点领导名、去括号
│   ├── 场景骨架.md              六类汇报各自的结构模板
│   ├── 美化规范.md              视觉基线：字体、字号、间距、配色、禁止事项
│   └── 视觉技法库.md            可选的高级视觉效果 CSS 代码
├── assets/
│   └── 汇报页模板.html          生成汇报页的起点模板
└── examples/
    ├── 示例-双周汇报.md         两轮产出长什么样（最值得先看）
    └── 示例产出-双周汇报.html    一份填好内容的成品页效果
```

## 常见问题

**Q：AI 说找不到这个技能？**
确认三件事：文件夹名是 `report-briefing`（不是 `report-briefing 2` 之类的副本名）；`SKILL.md` 直接在文件夹第一层；重启过 WorkBuddy。

**Q：生成的大纲一次就写满了，没有停下来等我确认？**
说一句「按 report-briefing 的第 1 步来，只出骨架」。如果还不行，说明 AI 没读到 SKILL.md，检查安装路径。

**Q：生成的页面在手机上排版乱了？**
模板自带移动端适配。如果乱，多半是改模板时删掉了 `@media` 那段 CSS，从 `assets/汇报页模板.html` 重新复制一份。

**Q：生成的汇报还是有 AI 味怎么办？**
直接说「按 report-briefing 的去 AI 味规则重查一遍」。也可以把手上写好的稿子贴过去，说「帮我查一下 AI 味」——这条短路不会重排结构，只逐句指出问题。

**Q：为什么六类汇报要去 AI 味规则不一样？**
因为病灶不同。双周汇报最容易犯的是「过程写得比结论多」，年度复盘最容易犯的是「挑战与展望」这个结构，述职最容易犯的是「谄媚和假谦虚」。一套通用清单挡不住这些。所以规则按类型分开，你得选对类型。

**Q：装了 `renhua` 或 `humanizer` 还要这个吗？**
要，但用途不同。那两个是通用去 AI 味（面向公开发表、技术文章），本 skill 的规则是给**商务汇报**调过的：删掉了口语化规则，补了汇报场景特有的毛病。写汇报用本 skill，改文案用那两个。

**Q：能把汇报页变成 PPT 吗？**
本 skill 只出 HTML（可打印成 PDF）。需要可编辑的 PPTX 时，配合 `ppt-master` skill 使用：先由本 skill 定内容，再用 ppt-master 做页面。

**Q：数据敏感，能放心用吗？**
这个 skill 完全在本地运行，不联网上传任何数据。生成页面时引用的字体 CDN（jsdelivr）只传输字体文件，不含你的内容。涉及经营数据的汇报，建议在生成后检查一遍再发送。
