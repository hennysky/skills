# 视频转讲义 skill · 安装说明

给谁看：想把 B 站课程、讲座、发布会视频转成能搜索的讲义页的自己。全程 3 步，第一次约 10 分钟（大部分时间在等 1.5 GB 模型下载）。

---

## 这个 skill 是干什么的

丢一个 B 站链接（或本地视频），产出四样东西：

1. **逐字稿** —— 带时间戳的 Markdown，另存一份 SRT，可导入剪辑软件
2. **章节地图** —— 按停顿切段、按内容划章节
3. **拆解报告** —— 由 AI 读完逐字稿后写：结论、观看地图、要点、能力边界
4. **单文件 HTML 讲义** —— 目录跟随滚动、逐字稿即时搜索、深浅色、可离线打开、可打印

一句实话：**转写是自动的，拆解不是。** 技能保证流程、结构、自检；判断质量取决于写它的模型。

## 安装三步

### 第 1 步：拿到文件夹

把整个 `hennysky-bili-lecture-digest` 文件夹放到技能目录：

```
~/.workbuddy/skills/hennysky-bili-lecture-digest     # WorkBuddy
~/.agents/skills/hennysky-bili-lecture-digest        # DSH / DeepSeek Harness
```

> 按你用的客户端选一个即可。`~` 是主目录，访达里 `Cmd+Shift+G` 输入路径可直接打开。

### 第 2 步：装两个命令行工具和模型

```bash
brew install ffmpeg whisper-cpp

mkdir -p ~/models/whisper
curl -L -o ~/models/whisper/ggml-large-v3-turbo.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
```

模型 1.5 GB，只在第一次下载。装完跑一次环境自检，缺什么它会直接告诉你装什么：

```bash
python3 ~/.agents/skills/hennysky-bili-lecture-digest/scripts/doctor.py
```

七项全 `PASS` 就可以用了（`yt-dlp` 标 `WARN` 不影响，只是少一层兜底）。

模型路径可以用环境变量 `WHISPER_MODEL` 指到别处。

### 第 3 步：重启客户端

技能靠文件夹识别，**文件夹名不要改**。重启后说一句「把这个视频做成讲义」即可。

## 验证装好了

先拿一段短片段跑，5 分钟就够：

```bash
SKILL=~/.agents/skills/hennysky-bili-lecture-digest   # WorkBuddy 用户换成 ~/.workbuddy/skills/...
python3 $SKILL/scripts/fetch.py "BV1tVxx6SEus" --out ~/Desktop/讲义/测试 --max-seconds 300
python3 $SKILL/scripts/transcribe.py ~/Desktop/讲义/测试
python3 $SKILL/scripts/build_page.py ~/Desktop/讲义/测试
python3 $SKILL/scripts/check.py ~/Desktop/讲义/测试
```

看到 `结果：通过` 就好了，打开 `~/Desktop/讲义/测试/index.html` 能看到逐字稿和搜索框。

**装之前想先看效果？** 直接打开仓库里的 [`examples/sample-lecture/index.html`](./examples/sample-lecture/index.html)——那是一个虚构内容的样例，展示了生成页面的目录、表格、公式和搜索。

参考速度：M1 Pro 上 5 分钟音频约 28 秒转完，61 分钟全片约 6 分钟。

## 常见问题

**为什么不用 B 站自带的字幕？**

官方字幕接口要登录态，而且只有部分视频有字幕。直接下音频本地转写更稳，也不受视频限制。

**转出来有错字怎么办**

同音字（比如「跨境电商」转成「跨境电线」）是 ASR 的固有毛病。往 `glossary/zh-common.txt` 里加一行 `错=>对`，或在自己项目目录放一个 `glossary.txt`，重跑转写那步即可。通用词别往里加，容易改坏原文。

**会不会哪天突然不能用**

B 站的音频地址要签名，平台改风控就会失效。脚本在失败时会自动改用 `yt-dlp` 兜底（`brew install yt-dlp`），两个都挂就需要修一次——这不是发出去就不用管的东西。

**要花多少磁盘**

中间会生成 16k 单声道 wav，1 小时约 112 MB。不想留就转写时加 `--clean-audio`，成功后自动删掉。

**能批量吗**

能。`SKILL.md` 里有 for 循环模板，一次十几个没问题，但**同时别超过 2 个**（每个占 1.5 GB 内存 + GPU）。
