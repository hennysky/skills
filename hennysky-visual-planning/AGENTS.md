# 可视化规划开发规则

- 当前是独立项目；使用本目录的 `bin/visualplan.mjs` 和模块，运行时不得依赖另一份 Skill 的安装目录。
- `package.json` 是项目版本源。升版同步 `skill-release.json`、Skill 元数据、模板 generator 和变更记录，执行 `npm run check:identity`。
- 保留十种原生图、整页说明和现有交互/导出能力。修复命名、布局或打包后，运行相关真实生成/浏览器回归。
- 产品展示统一使用“可视化规划”名称，不加推广与宣传语；第三方原文版权和许可不得抹除。
- 完整计划以 Markdown 为源，网页由构建器生成，检查内容指纹；阅读勾选不等于业务验收。
- 开发在 `codex/` 分支；相关检查、一次集中审查和分支集成后再提交发布记录。未经对应授权不发布远程或生产。
- 交付结论应列明已验证与未验证范围；可复现失败补回归，不用缩减图义或删掉步骤掩盖失败。
