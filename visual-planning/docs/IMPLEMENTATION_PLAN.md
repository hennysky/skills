# 可视化规划独立项目实施计划

建立一个可独立安装和维护的完整可视化项目，统一使用中性名称，并把流程图、待办和完整实施正文交付到同一页面。

## 目标与范围

包含十种原生图、整页说明、图表、主题、动效、导出、校验和预览。新增计划同源构建和 DSH Markdown 交接。运行时不依赖另一个 Skill 的目录。

## 现状依据

当前源码快照含 203 个文件，包含渲染器、schema、命令入口、阅读器、字体与图标。原有开发脚本依赖包外目录，需要改为本项目内命令。来源文件指纹和许可保留于 `licenses/`。

## 关键决策

产品版本独立从 `1.0.0` 开始。产品名为可视化规划，展示品牌为可视化规划，不加宣传语。运行代码和 Skill 正文采用独立命名；许可与非显示版权注释保留原文。

完整 Markdown 是实施内容的唯一源，页面源稿由构建器转换。目录跳转、主要图和返回链接自动加入，实施正文不缩略。

## 涉及文件或模块

| 模块 | 作用 |
| --- | --- |
| `bin/visualplan.mjs` | 独立命令入口 |
| `renderers/`、`schemas/` | 十种图的渲染与校验 |
| `explainer/` | 整页阅读、待办和交互图展开 |
| `scripts/planning-page.mjs` | 同源构建和内容一致性检查 |
| `scripts/package_skill.py` | 生成可独立安装的 Skill 包 |
| `SKILL.md` | 自动发现与工作流程 |

## 接口与数据结构

构建参数包含 `--plan`、`--diagram`、`--type` 和 `--out`。输出目录包含完整 DSH Markdown、图规格、页面源稿、网页、文件指纹和引擎收据。内容变化后检查会失败，须重新生成。

待办进度仅保存于读者本机，按页面修订隔离。源文件的完成状态与实际执行证据分别维护，不能把勾选当成验收通过。

## 测试命令与验收

```bash
npm test
npm run check:syntax
npm run check:brand
npm run check:validators
npm run smoke
```

验收要求包括完整图型渲染、整页内容一致、目录跳转、交互图展开、待办持久化和修订隔离、桌面与窄屏阅读。导出格式分别实测，未执行的格式不宣称通过。

## 风险与回滚

品牌替换可能影响内部协议或 schema 引用，须通过真实生成和校验复查。计划源变更后旧网页会变旧，内容指纹应拒绝失配。清单的本机进度不能代替业务完成。

本轮不涉及生产部署、业务数据库或消息发送。安装新 Skill 时保留现有技能；回滚只移除本项目安装目录，源码和交付保留。
