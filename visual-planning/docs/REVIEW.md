# 1.1.0 集中审查

本次是 Codex 本地审查，不代表独立人工批准。

- 新布局由 `meta.layout=planning` 明确选择；构建器默认选择，通用说明的布局保持原状。schema、解析器与预编译校验器同步支持该字段。
- 完整 Markdown、图规格和生成源稿继续受指纹检查约束，没有以摘要替代正文。目录、章节数、图数、待办数量取自实际内容。
- 规划样式偏好独立保存；桌面目录侧栏和手机折叠目录共享章节锚点，返回链接可重新展开目录；页面底部可定位最后章节。
- 章节编号使用实际文字，避免只在伪元素中显示而导致可读性和辅助技术检查失效。手机宽图和宽表格局部滚动，不撑破页面。
- 打印展开并保留目录。长图在隔离的 Shadow DOM 中测量展开后的实际高度，保留当前勾选值，避免最后章节裁切。临时测量节点始终移除。
- 页内交互图沙箱与十种原生图引擎保留，未放宽浏览器门禁。新布局、打印、导出和样式边界有对应回归和当前浏览器证据。
- 同步 1.1.0 元数据和示例 generator，保留 1.0.0/1.0.1 Git 历史、原文许可、既有交付及安装备份。没有远程或生产操作。

具体范围、实测证据与未验证项见 `VERIFICATION.md`。
