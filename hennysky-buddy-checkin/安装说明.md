# 积分 skill · 安装说明

给谁看：想在自己电脑上自动领 WorkBuddy「Buddy加油站」积分的同事。全程 3 步，第一次约 5 分钟（主要是扫码和等环境自动装好）。

---

## 这个 skill 是干什么的

每天自动把 Buddy加油站里**所有能自动领的积分**领掉，不用你点任何按钮：

1. **每日签到** —— 100 积分
2. **Buddy出车奖励** —— 你的 Buddy 出车回来带的 5～10 积分，以前要等弹窗，现在主动去问有没有待领的
3. **顺便报个余额** —— 领完告诉你当前积分

领不了的类型（邀请好友、购买返利这类要真人操作的）自动跳过，不会瞎报错。

原理说明：不模拟点击界面（那需要 macOS 辅助功能授权，且弹窗不一定出现），而是复用你自己网页版的登录态，在后台浏览器里调用平台自己的领取接口。

---

## 安装三步

### 第 1 步：拿到文件夹

把整个 `hennysky-buddy-checkin` 文件夹放到：

```
~/.workbuddy/skills/hennysky-buddy-checkin
```

> `~` 是用户主目录。访达里按 `Cmd+Shift+G` 输入 `~/.workbuddy/skills` 回车即可打开；`skills` 不存在就新建一个。

### 第 2 步：自检 + 登录

在终端里依次执行（路径按你机器的实际情况改）：

```bash
PY=~/.workbuddy/binaries/python/envs/default/bin/python3   # WorkBuddy 自带，通常都有
[ -x "$PY" ] || PY=python3
SKILL=~/.workbuddy/skills/hennysky-buddy-checkin/scripts/claim.py

$PY $SKILL doctor   # 自检：环境 / 登录态 / 接口连通
$PY $SKILL login    # 弹浏览器，微信扫码一次
```

`doctor` 会告诉你缺什么。`SESSION missing` 是正常的（还没登录）；`PLAYWRIGHT missing` 也不用管——第一次运行 `claim` 时脚本会自己在技能目录里建虚拟环境装好。

`login` 会弹出一个 Chrome 窗口停在扫码页，**用微信扫一下就好，只需要这一次**。看到 `LOGIN_OK` 即成功，登录态存在本机 `data/session.json`（权限 600，只属于你自己）。

### 第 3 步：让 WorkBuddy 每天自动跑（关键，别漏）

登录成功只是「能领」，还差一个每天触发的东西。在 WorkBuddy 里说：

> 帮我建一个每天 9:30 的自动化任务，执行 `$PY $SKILL claim`，按输出的 OVERALL / CHECKIN_RESULT 汇报结果

或者直接把 `SKILL.md` 里「定时任务 prompt 模板」一节交给它，让它按模板创建。

> 为什么不装系统定时器（launchd/cron）：多数 macOS 上第三方进程注册系统定时器会被直接拒绝（`launchctl bootstrap` 报 I/O error、`crontab` 报 operation not permitted），所以定时统一交给 WorkBuddy 自动化。

## 验证装好了

手动跑一次领取：

```bash
$PY $SKILL claim
```

看到 `OVERALL OK` 就对了。可能是：

- `CHECKIN_RESULT OK` —— 刚领到今天的积分
- `CHECKIN_RESULT ALREADY_CLAIMED` —— 今天已经领过了（正常，每天刷新）
- `TRAVEL_RESULT NONE` —— 暂时没有待领的出车奖励（正常）
- `BALANCE xxx` —— 当前积分余额

## 常见问题

**登录过期了怎么办**

说一句「重新登录加油站」，或手动跑 `$PY $SKILL login` 再扫一次码（30 秒）。定时任务第二天自动恢复。

**会不会误领、重复领、花钱**

不会。领取接口是幂等的，重复调用只会返回「今天已签到」；脚本只做领取和查询，完全不碰充值、支付、套餐变更。

**登录态安全吗**

`data/session.json` 等同你账号的钥匙，权限 600，只存在本机，**不要提交到任何仓库、不要发给任何人**。本仓库的 `.gitignore` 已排除。

**哪天突然不灵了**

接口是照着网页版前端扒出来的，平台改接口或活动下线就会失效，需要重新适配。这不是发出去就不用管的东西。
